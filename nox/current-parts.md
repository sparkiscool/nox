# Current parts: live status

The only live status of every part: one row per part, its state in the State cell and nowhere else. Numbers: `nox/dimensions.md`. Open problems and questions for Spark: `nox/open.md` (cited here by number). History: `nox/log.md`. State words and who moves them: `docs/workflow.md`. Re-read right before writing; change only your own rows; one cell per fact; no history in a cell (it goes in `log.md`).

State words: DESIGN · BUILT · READY · PRINTING · PRINTED · TESTED · FAILED · HOLD · ON HAND. READY means the file is committed in `print/`. Every READY part made before 20 Oct still owes a `solid_check.py` run by its owner before its next print (Problem 51).

Scout v2 is retired; its last table is frozen in `archive/scout-v2/current-parts.md`.
