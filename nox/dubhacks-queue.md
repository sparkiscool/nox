## How it works
This page holds **print order and print notes only. Every part's state lives in one cell: its row in `nox/current-parts.md`.** Never write a state here.
1. A design chat finishes a part (`nox/README.md` Printing, Done = saved): same turn, it publishes the file into "Nox Print Files" as `<part>_<version>.<ext>.b64.txt`, names that file in its row below, sets its `current-parts` state to READY, and writes its log line. It never needs the laptop.
2. Spark tells a linked chat "next" (or a printer finishes). That chat syncs `Documents\Nox\latest\` (README Printing, Latest folder), takes the top row below whose `current-parts` state is READY, opens that part's file from `latest\` in the Bambu Studio window that is already open (never launch a second copy; close other project windows), runs `print_orient.py` on it, slices, reports bed face / bed contact (M) / time / g / support g, Spark confirms the bed is clear, sends.
3. Same turn: one row in `nox-print-log.md`, `current-parts` state PRINTING. When Spark reports the result: PRINTED, or FAILED with a failure-log line. That's all the logging.
