Box catch · hook idea · Overseer cage v5 + Scout v11 · 27 Oct

Land on a flat pad, then four hooks pull it home

The deck is flat with the hooks folded flush, so nothing has to clear either cage while it lands. Once the drone is down, the box (which knows which drone it is) raises the hooks. Each one sweeps in under a bottom corner and pulls it out into a V-seat. When all four are closed, the drone is centred in x, y and yaw and locked down for the swap. Both drones put a bottom node on the same 4 points (the Overseer's hexagon side nodes), so the same 4 hooks serve both.
