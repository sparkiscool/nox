## Problems
1. **Overseer:** not drawn (Spark 17 Oct 02:02: Scout only). A full Overseer cartridge (est. 153 x 51 x 57 E) carried at park reaches r ~107 and only just fits the 30° sector at r 100: grow R ~9 or lower its cartridge when it is designed. Its module reuses this joint pattern (Y 145 / 209).
2. **Module overhangs:** v4i needs ~21 g tree supports each (E, 2714 mm² over 45°). Accepted for this build (no rerun).
3. **Joint stiffness:** the joints sit only at the outer rim (lugs r 172) and r 157 (dovetail); the inner edges near r 100 are unjoined. With the frames the ring is closed through the funnel (end frames' pads), which takes the racking out of each joint (stand v6); check the first chain by hand anyway; add an inner lug pair if it racks.
4. **No cell balancing in the box (17 Oct 01:18):** charging through the main lead only never balances the packs (`archive/scout-v2/s2-contacts.md` Problem 5). Fix (DEFAULT): CHECK the charger charges LiPo with no balance lead; charge in the box to 4.15 V/cell (E); balance-charge each pack on the bench every 10 cycles (E) or when a cell checker shows > 0.05 V spread (E).
5. **Funnel and drone centre along the axle:** the tab line is Y_C 175, so the seated pack is centred near Y 177; the collar sits on Y 177 on the end frames' pads (`box-stand.md` v6). The collar panels themselves are unchanged.
6. **Dead-end spikes (Spark 17 Oct 09:2x):** the smoothed surface can leave a horn that carries no load. Fix for every generated part: before sending, look for dead-end branches (skeleton endpoints away from drawn parts) and trim them flush with a plane or box at the nearest drawn face.
7. **Module dovetail flanks have 0 clearance** (found 19 Oct): `arm_cad._dovetail(-1, 0.2)` grows width and depth by 0.2 together, which slides the groove's 45° flank along itself, so it lies on the nominal tongue's flank (C). Fix: sand / file the −90 module's tongue flanks ~0.2 before joining the −60 module; next module version grows the groove width only (as `stand_v6_parts.groove_frame`).
