Box catch · hook idea, one servo · Overseer cage v5 + Scout v11 · 27 Oct

Land on a flat pad, then one servo pulls four hooks home

The deck is flat with the hooks folded flush, so nothing has to clear either cage while it lands. Once the drone is down, one servo pulls a lift frame down under the deck. A sprung link from the frame turns each of the 4 hooks in its own diagonal plane, so each hook sweeps up under a bottom corner and pulls it out into a V-seat. With the frame at the bottom, the links sit over-centre: the drone is centred in x, y and yaw and locked for the swap, with the servo unpowered. Both drones put a bottom node on the same 4 points (the Overseer's hexagon side nodes), so one set of hooks serves both. No keep-alive contacts.
