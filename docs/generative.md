# Generative parts and heavy runs

Every generated part runs the whole `nox/noxopt_demo.py` pipeline, in order, nothing skipped. A part script is a copy of the demo with the part's own loads, drawn features, cuts and envelope. Default optimizer: `noxopt.py` (layout + smooth build); `printopt.py` is the FE kernel and the strength checker. Tags: T measured in a cloud run, E estimate.

## Heavy runs (generative / topology / FE)
- One heavy run per session, on branch `run/<part>-<version>`. The control conversation starts one thread per run; a thread never waits on another. The `run-part` agent (`.claude/agents/run-part.md`) does a run end to end.
- Start it in the background (`nohup python3 <script> > runs/<part>/<version>/log.txt 2>&1 &`): the box only runs while a command runs. Checkpoint every ~10 iterations and **commit + push the checkpoint each time** (`git add runs/<part>/<version>; git commit -m "ckpt <n>"; git push`). A reclaimed box keeps the branch, not the files. `run(resume=...)` continues from a checkpoint.
- Report only the final numbers. Hard cap 6 h, then build from the last checkpoint.
- Peak memory: measure once at start (`/usr/bin/time -v` or `psutil`), tag it, keep peak under 75 % of the machine. Runs above ~60k design cells use `noxopt_local` with `backend="gmg"`.
- `python3 nox/test_noxopt.py` once per session after any engine edit; never otherwise.
- Done: `runs/<part>/<version>/summary.md` in the Done = saved form (`docs/printing.md`), `result.json` (mass g M, worst index + case, solid_check pass, bed face, bed contact mm², peak memory GB, wall time), `preview.png`; then `python3 tools/runs_index.py`, commit, push, PR.

## The rule
1. **Drawn = mounting + must-haves only:** fastener seats, mating and contact faces, pin bores, rod sockets, connector seats; flexures, hooks, lens and sensor windows, TPU feet. Each at its smallest volume. Everything else is generated. Remove any other drawn geometry before the run and say what was removed. Attachments follow `docs/rules.md` (pads ≥ Ø12, posts ≥ 6 x 6, gussets). **Every drawn body lies inside the envelope (the build clips to it), and the design space must be able to reach each drawn body over its whole length, not only at a tip.** A bolt pad includes its boss: the wall round the counterbore is drawn.
2. **Layout:** stiffness run to a mass target, every load case plus a tie load on every drawn feature. Members come out at the filter radius (at least 2.0 mm and 2 cells). Symmetric mounting gives a symmetric part: centre the grid on the mirror plane, build one half and mirror. Pick the bed face first (`docs/printing.md`): the drawn mounting pads are usually it.
3. **Stop** at ≤ 2 % grey and settled. Hard cap 6 h, then build from the last checkpoint. Too big means coarser or in pieces.
4. **No thin rods:** `prune_thin` after the layout; `thin_check` reads 0 after the build. A thin member goes back to `prune_thin`, never thickened by hand.
5. **Build:** `smooth_surface` polish (fillets where members meet, holes stay holes, nothing under 2.0, off every keep-out), then exact drawn bodies, envelope trim, exact cuts. Mounting features are never smoothed. `function_check` reads 0 / 0 / 0. Report `wrinkle`; look at close-ups; lumpy means rebuild.
6. **No patching:** no grey fill, dilation, member growing or "keep the largest body". One body holding every drawn feature; a detached feature means rerun. **`solid_check` PASS or the part does not exist.**
7. **Strength:** as-built recheck of every case (`printopt.py` layer-aware index). A must-hold case over 1.0 gets local reinforcement, at most 3 passes; a remaining miss is noted. **A topology part replaces a drawn one only if it beats the drawn part's worst index on the same FE (same grid) and passes the solid check; the FE grid must be at most a third of the smallest neck it has to judge.**

Done when: `solid_check` PASS, one watertight body, interfaces exact, function check 0 / 0 / 0, thin check 0, fit vs mating parts, wall check, smooth, mass vs last version, `print_orient.py` pass.

## What you need
- **Engine:** `nox/noxopt.py`, `printopt.py`, `test_noxopt.py`, `render_preview.py`, `noxopt_bench.py`, `noxopt_demo.py`, `noxopt_local.py`, `solid_check.py`, `print_orient.py`. Don't read the engine through the chat.
- **The part's own script** from the repo (box parts: `nox/box/`). It builds a `printopt.Problem` (masks, supports, load cases) plus the exact bodies. A worked part on the demo pattern: `nox/box/arm_topo.py` (generic pipeline for a part given as manifold bodies) with `arm_run_*.py`; drawn-plus-topology stand parts: `nox/box/stand/stand_v7_topo.py` + `stand_v7_topo_build.py`.
- **Setup:** `cloud/setup.sh` installs pymoto, pypardiso + mkl, trimesh, rtree, manifold3d, scikit-image, scikit-fmm, matplotlib, cadquery, sparse_dot_mkl (~1 min, T); the SessionStart hook reinstalls them if a box lacks them. noxopt points pypardiso at pip's MKL itself, so import noxopt before pypardiso. `python3 nox/test_noxopt.py` is the self-test (finite-difference checks incl. the plain filter, a small end-to-end run, the smooth build without and with the polish, automatic symmetry, the thin-member check; 1.5 min, T) and `python3 nox/noxopt_demo.py 2.0` the demo (9 min, T: 10.4 g, thin 0, function 0 / 0 / 0, worst 0.32).

## The five steps (how-to)
Copy `noxopt_demo.py`, swap in the part's `Problem`, exact drawn bodies, cuts, envelope and mirror plane, keep every step.
1. **Drawn set.** Must-have features only (rule 1), each at its smallest size, as passive solid. Nothing seeded from an older version.
2. **Layout** (stage 1):
```python
import noxopt as NO
pb = <the part's printopt.Problem>          # pb.R = filter radius in cells, pb.overhang, pb.sym as before
L = NO.Layout(pb, volfrac)                  # volfrac = mass target, share of the design cells; masked=False = plain filter (shells)
dens = L.run(checkpoint="ck.npz", resume="ck.npz")
L.save("part_density.npz", dens)            # same file layout as printopt's
```
   noxopt adds the tie cases itself (3 unit loads on every drawn body the main support does not hold), runs the robust eroded / nominal / dilated formulation, raises the sharpness only when the layout has settled, and stops on greyness (≤ 2 % grey cells, or 30 iterations at the last sharpness). **Symmetry:** with `pb.sym` unset, `Layout` checks whether passive solid and passive void are identical under a flip about each grid mid-plane and holds the generated material symmetric about every plane that passes (log line; `auto_sym=False` for a one-sided design). A "nearly but not exactly mirrored" warning means cell centres do not land the same way on both sides: pick h so size / h is a whole number and no cell centre sits on a feature edge, or mirror the masks in the spec. One-sided load cases need no change.
   **Thin members, right after the layout:** `L, dens, removed = NO.prune_thin(L, dens, floor_mm=<wall class minimum>, margin_mm=<clip_margin + 0.25>)`. It finds every member that would be built under the floor, makes its cells void, and continues the layout from sharpness 8 so the load re-routes at full member size; up to 3 passes, ~50 iterations each. The re-settle keeps the run's `masked` choice. Use `L.pb0` (the pruned problem) for connectivity and the strength recheck; the build's `clip_mesh` stays the original keep-outs.
3. **Connectivity check:** `NO.connectivity(dens, pb)`. One body, every drawn body in it. Loose specks of a few cells are dropped at build and reported; a detached interface or a real loose member means fix the cases or the mass target and rerun, never patch.
4. **Smooth build** (stage 3): `NO.smooth_surface(rho_phys, solid, void, shape, h, origin, keep_mesh=<exact drawn bodies as one trimesh>, clip_mesh=<allowed region: envelope minus every cut>, floor_mm=<the part's wall class minimum>)` returns the polished generated surface with fillets into the drawn features, at unchanged generated volume. **Polish** (default; smooth like a bone, bumps only where structures merge, mounting features untouched): a locally volume-preserving mean-curvature flow on the distance field. A round member does not move; lumps, waists, warts, ridges, ripples and voxel steps flatten; joins fill into fillets. Pinned during the flow: the drawn bodies (never thinned), the holes (material grows at most `polish_hole` into the optimiser's voids), a `floor_mm` tube along every centre line of the layout (no member thins out or parts), and every keep-out (generated material held `clip_margin` + 0.25 inside, rounded over). A Taubin pass on the mesh away from the drawn bodies then takes out the marching-cubes facets. Then: union the exact drawn bodies, intersect the envelope, subtract the exact cuts, mirror if the part is symmetric. No grey fill, no dilation, no member growing, no "keep the largest body". `polish=False` gives the plain sigma-smoothed surface (comparisons only). Pattern: `build()` in `noxopt_demo.py`.
5. **Checks, then hand-off:** fit suite; as-built strength recheck (voxelise the STL, `printopt` evaluate, every case; pattern: the end of `noxopt_demo.py`, `nox/box/arm_recheck.py`); if a must-hold case reads over 1.0, pass the hot cells back as `smooth_surface(..., reinforce=points)` (balls r 1.2 to 1.8 mm, design cells only, added mass reported) and recheck, at most 3 passes; wall check; **function check:** `NO.function_check(part, drawn, cuts, allowed)` must read 0 / 0 / 0; **thin check:** `NO.thin_check(part, drawn, floor_mm)` must read 0 members; if it finds one, `NO.prune_thin(L, dens, built=<its list>)`, build again; **smoothness:** `NO.wrinkle(part, drawn=<drawn bodies trimesh>, allowed=<allowed region trimesh>)` reported (p95 / p99, 1/mm, generated surface only), plus close-up renders of the generated surface (top and underside) that the session looks at before "ready to print". Anything lumpy is rebuilt, not printed: long swells and waists along a member, or a crease where two members run side by side, mean the layout is too coarse; re-run the layout on a finer grid (gripper head: h 2.0 to 1.32, warm-started from the coarse layout at sharpness 4), not more flow. **Big fine runs: `noxopt_local.py`**: same spec, replace `NO.Layout(pb, vf)` with `import noxopt_local as NL; L = NL.Layout(pb, vf, backend="auto")` (`"pardiso"` = direct, `"gmg"` = multigrid CG with lean memory, `"auto"` picks by size and free RAM); same `run()`, checkpoints and `save()`, results equal to noxopt to the solver tolerance. Bench holder h 2.0, 40 it (T): gmg 1.60 s/it 0.46 GB, pardiso 1.36 s/it 0.44 GB. Use `"gmg"` past ~450k free dof, where a direct solve no longer fits in 6 GB (E). Then `render_preview.py` and the Done = saved update.

## Defaults (DEFAULT unless the part doc says otherwise)
| Setting | Value | Why |
|---|---|---|
| Grid | h 1.0 or finer; small parts 0.5 | members at least 2 cells wide |
| Filter radius `pb.R` | 2.0 cells, and at least wall class / h | sets the smallest member; members come out at this size, nothing is grown afterwards |
| Robust thresholds | 0.7 / 0.5 / 0.3 | eroded design carries the load, nominal is built |
| Case weighting | p-mean, P 4, each case / its solid-domain value; tie cases x 0.25 | every case counts, no single case starves the rest |
| Mass target | generated volume from the part's budget (`GEN_CM3`), then step it: lower while the as-built worst index stays ≤ 1.0 | |
| Overhang filter | **off** for parts on tree supports (the default since supports are allowed everywhere); on only for a part that prints flat with no supports | on a small-footprint part it wipes most of the part and one corner never attaches (T) |
| Stop | ≤ 2 % grey cells and settled; hard cap 6 h | not an iteration count |
| Smooth build | fine grid h / 4, sigma 0.6 mm at h 1.0 (scale with h: ~0.6 x h), volume preserved | rounds the voxel steps, fillets the joins |
| Polish | on; flow time `polish_T` 2 h² mm² (8 at h 2.0), curvature averaged over `polish_rho` 2.5 h, holes kept `polish_hole` 1 h, soft limits `polish_soft` 0.25 h, then 10 Taubin passes; `floor_mm` 2.0 (2.4 TPU); `clip_margin` 0.5 | gripper head v3 (h 2.0, T): wrinkle p95 / p99 0.28 / 0.39 to 0.20 / 0.28 (a smooth rod 0.18 / 0.21), function 0 / 0 / 0, worst 0.45 (as built 0.43), 98.0 g (102.3), one body |
| Load cases | all of the part's cases in the layout (cheap: one factorisation per support group) | stiffness runs need no adjoint solves |

Run time (2-core box, T): pocket masks at h 2.0 with 57 cases 8 s per iteration, 125 iterations, 17 min; cartridge at h 1.0 with 38 cases and 4 support groups 24 s per iteration, 144 iterations, 57 min. Cost grows with the number of support groups more than with the number of cases. A polished build of the gripper head (h 2.0, up 4) takes 16 to 18 min and peaks at 2.1 GB (T).

## No flat cut-offs
A flat face on a generated part means material ran into a limit and the exact cut sliced it. Before a run:
- **Envelope faces that are not real restrictions go out** until the layout stops touching them. Check after the run: count the generated cells in the layer next to each envelope face; a full layer means the box is still too small.
- **Empty skin:** design cells within 2.0 mm of an envelope face are void, except downward faces that sit on a mating part (plate, bed).
- **Build with the clip:** `NO.smooth_surface(..., clip_mesh=<envelope minus every cut, as one trimesh>, clip_margin=1.0)`. Generated material stops 1.0 short of a keep-out and rounds over; within `clip_near` (default 2 x margin + sigma) of a drawn body it still runs to the exact cut so mating faces stay exact.
- Report the sliced flat area per plane (faces of the built part lying on an envelope or cut plane, minus the drawn bodies' own faces). A real keep-out the layout presses against still gives a straight, rounded face 1.0 inside it.

## Known limits
- **Why thin rods appear (T):** the masked filter lets a member run flush along a keep-out wall at one cell wide, and the build then holds generated material `clip_margin` + 0.25 off that wall, which beats the polish's floor tube: a 1.6 mm rod on a 2.0 floor. `prune_thin` + `thin_check` are the fix; `thin_members` reads radii in steps of h / 3, so a member right at the floor can be pruned although it would have built at ~2.0.
- The layout is a stiffness design. Strength is checked on the built part and fixed locally (step 5); the full strength loop (stepping the mass target automatically) is not built.
- The voxel recheck reports peak values; a one-voxel peak with p99.9 well under 1.0 is a flag, not a failure. No tet recheck in the cloud.
- A member 2 cells wide is still coarse. Curvature flow cannot remove waves along a member longer than about its circumference, and where two members run side by side 1 to 2 cells apart the polish leaves a crease. The fix is a finer layout, not more flow: gripper head v3 at h 1.32 came out smoother and 9 % lighter than at h 2.0, worst index 0.59 vs 0.45 (T).
- `wrinkle()` without `drawn` / `allowed` mostly measures the sharp edges of drawn features; pass both. Its floor at pitch 0.4 is ~0.18 / 0.21 (smooth rod, sphere, torus, T). Compare a part with its own last version, not across parts.
- Tried and dropped (T): centre-line "bone" rebuild (rods smooth, webs lumpy, worst index up to 0.85); medial-surface rebuild (bumpy); centre lines for rods plus faired plates (seams); member truing (wavy patches); repeated fairing passes (long lumps stay).
- Hand loads on an empty part (cartridge pinch) are DEFAULT cases, added because a print was flimsy. Drop or change them per part.

## Large runs
- **RAM (T, 7 GB chat boxes):** a run at h 2.0 with 79601 design cells (581526 dof) was killed at 6 GB in the first solve; 53089 cells ran (42 s per iteration, 111 iterations, 79 min, 75 cases). Pardiso died at 6 GB; use `backend="gmg"`. Re-measure the limit on the first big run in a 16 GB box (E).
- **A box that does not fit in RAM:** run the whole box coarse first (h 3.0; the coarse layout is only a guide to where material goes), then run h 2.0 with the design cells outside that region plus ~10 mm set void. After the run, count generated cells in the outer 3 layers of the trimmed region: 0 means the trim did not restrict anything.
- **Mass target when the box grows:** give the generated volume, not a share (`GEN_CM3=30.4`); the share falls as the box grows.
